Guide

使用說明

Check Board

  • 左側是目前檢查的source class，右側是依序檢查的target class。
  • 按 ✓ 接受目前關係，按 ✕ 選擇錯誤原因並拒絕。
  • 選擇「其他」時，需要填寫原因後才能確認拒絕。
  • 「↩」可撤回上一筆判定並回到上一個 target。

Result

  • Radial Tree 以放射狀圖顯示目前已接受的 ontology 結果。
  • Ontology Result 以階層樹狀清單顯示已接受的 class path。
  • 點選Radial Tree 或 Ontology Result 中的已接受 class，會同步切到「Accept」並進入 Edit mode。
  • 未被接受的 class 不會出現在 Result；若需要修改，請從「Reject」進入編輯。

Definition

定義說明

Sense

  • 「buildings」:描述建築的基本構成，包含:空間元件,建築元件,構造元件等等。
  • 「participant」:描述建築案例涉及到之利害關係人。
  • 「event」: 描述建築案例事件或時間相關的概念。
  • 「issue」:描述建築中的議題。
  • 「site」:描述建築中的基地相關內容。

Relation type

  • 「has feature」:children(material)類別為parent(facade)類別的屬性特徵。
  • 「has subclass」:children(museum)類別為parent(building type)類別子類別。
  • 「has data」: children(height)類別為parent(room)類別子類別。
  • 「has part」:children(wall)類別為parent(building)的部分(可分割)構成。

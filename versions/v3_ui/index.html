Introduction of Ontology

甚麼是本體?

What is Ontology?

Ontology 是一種用來整理與定義概念、關係與屬性的知識結構，幫助人和系統用一致的方式理解同一個世界。

Example:
  • subclass(概念上/下位關係): Bedroom(臥室) 是一種 Room(房間) 。
  • part of(概念之間「部分/包含」關係): Window(窗) 是 Wall(牆) 的一部分。
  • feature attribute(概念的特徵屬性): Orientation(方位面向) 是 Room(房間) 的特徵屬性。
  • data attribute: Room Area(房間的面積) = 12 m²。

Kase Ontology 本體介紹

Kase Ontology 是專為建築案例資訊建模的本體，最上層的概念幫含一下五個面向:

  • building 表示建築相關的類別，例如空間、構件、材料或建築型態。
  • participant 表示參與者或角色類別。
  • event 表示事件、活動或行為類別。
  • issue 表示問題、議題或設計考量。
  • site 表示基地、環境或場域條件。

Kase Ontology Relation type

  • has feature 表示 children 是 parent 的特徵或屬性。
  • has subclass 表示 children 是 parent 的子類別。
  • has data 表示 children 是 parent 的資料屬性。
  • has part 表示 children 是 parent 的組成部分。

Guide

介面說明

Corpus Window

  • 視窗為當前Case完整敘述內容，以及被框選的待「分類實體」。
  • 「分類實體」可以透過滑鼠選取，並在Ontology Browser視窗進行分類。

Extracted Terms & Populated Terms

  • 「Extracted Terms」 會顯示所有「待分類實體」。
  • 「Populated Terms」會顯示所有「已分類實體」。

Ontology Browser

  • 完整本體操作面板，當選定「待分類實體」即可進行概念分類。
  • 點選「概念」後即會出現「Save」按鈕，點擊即可完成該實體分類。
  • 「+」為向下展開概念內容，「-」為返回上層概念內容。
